# 🛡️ zapret-winws-ru

Утилита для тонкой настройки и обхода ограничений сети в РФ на базе оригинального софта [zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle).

---

## 📂 Краткое описание файлов

* **`preset_general*.bat`** — Скрипты для быстрого запуска или установки приложения в систему.
* **`zapret_manager.bat`** — Главный интерактивный менеджер для управления всеми функциями утилиты.
* **`zapret_fake_manager.bat`** — Инструмент для переключения конфигураций фейковых пакетов (для Discord и онлайн-игр).

---

## ⚙️ Режимы игрового фильтра

* **`TCP/UDP`** — Полный перехват и модификация трафика по обоим протоколам.
* **`TCP`** — Работа только с TCP-трафиком (веб-сайты, базовые соединения).
* **`UDP`** — Работа только с UDP-трафиком (голосовые каналы, сетевой код игр).

## 🗺️ Режимы IPset фильтра

* **`ENABLED`** — Фильтрация применяется строго к адресам и доменам из встроенных списков приложения.
* **`DISABLED`** — Любая предварительная фильтрация адресов отключена.
* **`EMPTY`** — Экспериментальный режим. Пытается обрабатывать весь проходящий трафик «на лету» без списков. 
  ⚠️ *Внимание: может работать нестабильно и ломать доступ ко многим сайтам или играм. Используйте на свой страх и риск!*

---

## 🚫 Известные конфликты и зависимости

Программа использует системный драйвер **WinDivert** для низкоуровневого перехвата сетевых пакетов. Во избежание падения интернета и критических ошибок **не запускайте утилиту одновременно с:**

* **VPN-сервисами** — встроенные виртуальные сетевые карты и фильтры VPN перехватывают трафик раньше, полностью ломая логику работы утилиты.
* **Другими средствами обхода блокировок** — GoodbyeDPI, ByeDPI (ByeDPI Manager), GoodbyeDiscord и их аналогами. Они начнут конфликтовать за право обрабатывать пакеты.
* **Антивирусами и сторонними фаерволами** — ПО от Kaspersky, Avast, ESET и др. может заблокировать установку драйвера WinDivert или удалить исполняемые файлы.
* **Античитами онлайн-игр** — агрессивные античиты уровня ядра (например, *Riot Vanguard* для Valorant/2XKO или *Faceit AC*) могут конфликтовать с драйвером перехвата на системном уровне.

---

## ⚠️ Важные примечания

1. **Права администратора:** Все исполняемые `.bat` файлы необходимо запускать строго **от имени Администратора**, иначе драйвер перехвата пакетов не сможет инициализироваться.
2. **Откат Discord:** При выполнении процедуры отката исправлений для голосовых каналов Discord, системный файл `Hosts` автоматически возвращается в оригинальное, чистое состояние (актуально для Windows 7 / 8.1 / 10 / 11).
